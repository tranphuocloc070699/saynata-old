In step 4 the keyboard swaps its letters for the change list. Tapping any letter area or the ✓ again brings the keys back. Highlights in the text box are only for this mockup: a keyboard can't colour text inside another app.

How it works inside

iOS gives a keyboard one door into the text box: textDocumentProxy. It can read the text around the cursor, delete characters, and insert text. That's enough to swap the sentence.

The swap, in Swift (sketch)

let proxy  = textDocumentProxy
let before = proxy.documentContextBeforeInput ?? ""
let after  = proxy.documentContextAfterInput  ?? ""
let fix    = try await api.fixSentence(before + after)

// put the cursor at the end, then delete the old text
proxy.adjustTextPosition(byCharacterOffset: after.count)
for _ in 0..<(before.count + after.count) { proxy.deleteBackward() }
proxy.insertText(fix.corrected)

// keep the old text, so the undo button can swap it back
lastOriginal = before + after

The catches

TopicWhat happensImpact
How much textiOS gives the keyboard only the text near the cursor, usually the current paragraph. Fine for chat messages; long messages may be cut.fine for chat
Full AccessA keyboard needs "Allow Full Access" to use the network. iOS shows a scary warning when you turn it on.one-time setup
Where it can't runPassword fields, phone-number pads, and apps that block third-party keyboards. Telegram and Discord allow them.fine
Sign-inThe keyboard needs your account token. Sharing it with the app needs App Groups / keychain sharing, which needs the paid account (PAID_ACCOUNT=1). With a free Apple ID, the keyboard has to sign in on its own.check this first
MemoryKeyboard extensions have a tight memory limit. Keep it small: no word cards or pictures inside it, only the fix and the change list.design for it
App StoreApple expects a keyboard to actually type, so it needs a full set of letters, not just the ✓ button. Not an issue on your own phone.more work to ship

What gets built

1. Backend: POST /api/sentence/fix with a new prompt and prompt version, through ClaudeGate. The Mac Service and option A reuse it.
2. iOS: a new SaynataKeyboard target with the letter keys, the ✓ and undo buttons, and the change list. Both buttons are icon-only with VoiceOver labels.
3. Settings page in the app: "Add the Saynata keyboard" steps (Settings → General → Keyboard → Keyboards → Add, then Allow Full Access).
