If you select text you're reading (a friend's message), iOS doesn't allow replacing it. The sheet then looks like it does today: explanation first, no Fix card. The Fix card only appears when there's text you can change. Highlights in the text box are only for this mockup.

How it works inside

iOS 18.4 gives the default translation app a TranslationUIProviderContext. It holds the selected text, a flag that says whether the text can be replaced, and a method that puts new text back in its place.

The change, in Swift (sketch)

private struct TranslationSheetView: View {
    let context: TranslationUIProviderContext

    var body: some View {
        let text = context.inputText.map { String($0.characters) } ?? ""
        if context.allowsReplacement {
            // you're writing: show Fix card + ✓, explanation folded
            FixSheetView(text: text) { corrected in
                context.finish(translation: AttributedString(corrected))
            }
        } else {
            // you're reading: today's explain sheet, unchanged
            SelectedTextResultView(loadText: { text })
        }
    }
}

Today the code says on purpose: "There is no Replace with translation button (Saynata explains, it does not replace)". Option A changes that only for text you wrote yourself, and the replacement is the corrected English, never a translation. That fits the "explain first" rule. It's still a product decision, so it goes in doc-7.
