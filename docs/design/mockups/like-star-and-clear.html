A · Built-in “replace”

Plain icon, same as the copy and star icons under a sentence. Star shrinks, check grows in, then star comes back filled. SwiftUI .contentTransition(.symbolEffect(.replace.downUp)) + .sensoryFeedback(.success).

B · Check draws itself

Same small plain icon. Star pops away, the check mark draws left to right (feels like “saved”), then the filled star pops back. Pure SwiftUI: Shape.trim(from:to:) + a spring. Works with the custom rounded star, which A cannot (symbol effects only run on SF Symbols, so A would need the sharp star).

Libraries checked: Lottie and Rive can do this, but each adds a package (~1–3 MB) and an animation file made in another tool, for one 1-second effect. Built-in SwiftUI is enough. Reduce Motion: no movement, just the filled star.

contentTransition · ReplaceSymbolEffect · Shape.trim
